## Start a session

Open a session in this folder or in a work folder, name the work, and say what you want. For example: "Continue the website relaunch."

The agent reads the folder's hand-off first and updates it when a task is done. Close the chat whenever you like. The next session starts from the hand-off.

## Work folders

Every project and area folder starts with the same six files: `README.md` (what the work is), `{{HANDOFF}}` (where it stands), `DECISIONS.md`, `AGENT_SYNC.md`, `AGENTS.md` and `CLAUDE.md`. Each one links back up to this map.

The agent-workspace-setup skill writes the tables between the markers. Write your own notes anywhere outside them.
